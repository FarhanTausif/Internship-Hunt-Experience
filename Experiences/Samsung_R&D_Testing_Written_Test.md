# Samsung R&D Testing Written Test

This document outlines the topics and questions covered in the Samsung R&D written test for a testing role.

## Testing Fundamentals

The test included questions on basic testing concepts, such as:

*   **Flaky Test:** A test that passes and fails intermittently without any code changes.
*   **Smoke Test:** A preliminary set of tests to reveal simple failures severe enough to reject a prospective software release.
*   **Alpha Testing:** In-house testing by internal teams before the product is released to external users.
*   **Beta Testing:** Testing by a limited number of external users (beta testers) before the official product release.

## Code Output Tracing

There were 3-4 code snippets in C/C++, Python, and Java. The task was to trace the execution and predict the final output of each program.

## Artificial Intelligence / Machine Learning Basics

The test included fundamental questions about AI and ML, covering topics like:

*   **Supervised vs. Unsupervised Learning:** What are the key differences between supervised and unsupervised learning paradigms?
*   **Underfitting and Overfitting:** Explain the concepts of underfitting and overfitting a model.
