# Samsung R&D Internship Interview Experience

This document outlines the questions and topics discussed during an internship interview at Samsung R&D.

## Personal and Project-Based Questions

*   **Introduction:** "Tell me about yourself."
*   **Resume Review:** The interviewer asked basic questions about the projects and information on my resume.
*   **Most Challenging Project:** "What has been your most challenging project so far, and why?"

## Object-Oriented Programming (OOP)

*   **Why OOP?** "Why do we use Object-Oriented Programming?"
    *   **My Answer:** "It allows for mapping to real-world objects."
*   **OOP vs. Structural Paradigm:** "C/C++ can also model real-world entities in a structural paradigm. So, why is OOP preferred?"
    *   **My Answer:** "Encapsulation."
*   **Public Data Scenario:** "What if the data I want to use is pre-decided to be public? Does encapsulation still provide an advantage?"
    *   **My Answer:** I was unable to provide a clear answer.
    *   **Interviewer's Feedback:** The interviewer explained that ambiguity can occur when including different header files that contain variables with the same name, and namespaces in OOP help resolve this.

## Data Structures and Algorithms (DSA)

*   **Array vs. Linked List:** "What are the differences between an array and a linked list?"
*   **Data Structure Selection Scenario:**
    You have a dataset with 10,000 data points.
    *   **Scenario 1:** The range of the data (both minimum and maximum values) is known.
    *   **Scenario 2:** Only the range (the difference between max and min) is known, but not the absolute min and max values.

    For each scenario:
    *   Which data structure would you use and why?
    *   What would be the approximate size of the data structure?
