# DSi Internship Interview Experience

This document outlines the questions and topics discussed during an internship interview at DSi.

## Personal and Project-Based Questions

*   **Introduction:** "Tell me about yourself."
*   **Resume Review:** The interviewer asked specific questions about the projects listed on my resume.
*   **Most Challenging Project:** "Which project did you find most challenging?"
*   **Use of LLMs:** "Have you used Large Language Models (LLMs) in any of your projects?"
*   **Areas of Interest:** "Which fields are you most interested in?"
*   **Exciting Fields:** "What field do you find most exciting?"
*   **Favorite Courses:** "What are your favorite academic courses?"
    *   My answer: Software System Design.
    This answer leads to the following array of questions. 

## Technical Questions

### System Design and DevOps

*   **Dockerfile:** "What are the basic components of a Dockerfile?"
*   **Load Balancing:** "What is load balancing?"
*   **Rate Limiting:** "What is rate limiting?"
*   **Nginx:** "What is the difference between a reverse proxy and a forward proxy in Nginx?"
*   **Rate Limiting Implementation:** "Have you ever implemented rate limiting yourself?"
    *   My answer: "No, I have used Nginx's built-in rate limiting. However, I am aware of several algorithms like Leaky Bucket, Sliding Window Log, and Sliding Window Counter."

### Databases

*   **NoSQL:** "Why is NoSQL so widely used?"
*   **Relational Databases:** "Have you worked with relational databases? If not, why?"
*   **Normalization:** "What is database normalization? Why do we use it? Can you provide an example?"
*   **Oracle SQL:** "Can you describe the basic operations in Oracle SQL?"
*   **Keys:** "What is the difference between a primary key and a unique key?"
*   **SQL Query Challenge:** "Write a SQL query to find the department of the employees with the highest total salary. You'll need to design the database schema yourself."
*   **Query Optimization:** "Why did you use a subquery? Would a JOIN have been more or less costly?"

### Data Structures and Algorithms (DSA)

*   **DSA Knowledge:** "Are you familiar with Data Structures and Algorithms?"
*   **Common Data Structures:** "Name some common data structures."
*   **Array vs. Linked List:** "What are the differences between an array and a linked list?"
*   **Binary Search:** "For a sorted dataset, which data structure would you prefer for binary search: an array or a linked list?"
*   **Space-Time Complexity:** "Can you achieve similar time complexity to an array with a linked list if you use auxiliary space?"

### Object Oriented Concepts 

* **Classic Design Problem:** "Design an object-oriented model for geometric shapes (Circle, Rectangle, Triangle, etc.) that supports:

    - Common behaviors (area, perimeter)
    - Extensibility for future shapes
    - Proper use of OOP pillars (inheritance, polymorphism, abstraction)

## Brain Teasers

*   **Candle Puzzle:** "You have two candles that each burn for exactly one hour, but they burn unevenly. How can you measure 45 minutes using these two candles?"
*   **Ball Puzzle:** "You have 8 balls, one of which has a different weight. Using a balance scale (without any weights), what is the minimum number of weighings required to find the unique ball?"
